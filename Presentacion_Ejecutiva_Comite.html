Content Security · Network Gate
Zero External Access
No content, link, or resource can be accessed from outside the Murex corporate network
FINANCE ONBOARDING
Not a single link, video, or training file stored in MXBoard can be opened from a computer disconnected from the Murex VPN. It is technically enforced — not a policy, a hard technical block.
1. Encrypted in Database
All resource URLs are stored AES-256 encrypted in Supabase. No media path or link ever appears in the frontend source code or HTTP responses.
Key Control
2. Murex VPN Exclusivity
Any request originating outside the Murex corporate network tunnel is blocked at the IP layer. No exceptions, no workarounds, no bypass route exists.
3. Expiring Signed Tokens
Every content request generates a single-use token with a short TTL. Any link shared externally is cryptographically invalidated the moment it expires.
RBAC · 3 roles, zero escalation
Immutable Audit Trail
TLS 1.3 End-to-End
Exportable Certification Record
